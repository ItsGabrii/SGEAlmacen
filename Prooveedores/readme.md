# Feature Proveedores

Esta carpeta contiene los recursos específicos de la gestión de **Proveedores** dentro del ERP.  
Incluye los archivos necesarios para crear, editar y mostrar proveedores en la sección de Almacén.

---

## 📁 Contenido de la carpeta

- `estilo.css` — Estilos específicos para la interfaz de Proveedores.
- `proveedores.php` — Formulario para insertar y editar proveedores en la base de datos.

---

## 🔧 Funcionalidades

La feature **Proveedores** permite:

- Registrar nuevos proveedores mediante un formulario.
- Editar proveedores existentes.
- Visualizar los proveedores en una tabla organizada y funcional.

---

## 🔄 Flujo de trabajo

- Todos los cambios relacionados con **Proveedores** deben hacerse en la rama `feature/proveedores`.
- No modificar otras carpetas (`Platos`, `Productos`, `/tools`) desde esta branch.
- Los cambios se integran a `main` mediante **Pull Requests**, asegurando que solo se vean los archivos de Proveedores.
