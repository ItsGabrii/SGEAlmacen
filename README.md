# Proyecto ERP - Sección Almacén

Este repositorio contiene el código y recursos relacionados con la sección **Almacén** del proyecto ERP.  
El objetivo es gestionar de forma centralizada y eficiente el inventario, productos, proveedores y demás funcionalidades propias del almacén.

---

## Estructura del repositorio

- `/Platos` — Funcionalidades y recursos específicos de la feature Platos  
- `/Productos` — Funcionalidades y recursos específicos de la feature Productos  
- `/Proveedores` — Funcionalidades y recursos específicos de la feature Proveedores  
- `/tools` — Archivos y utilidades compartidas, como scripts SQL, estilos y helpers  

---

## Flujo de trabajo

- La rama `main` contiene la versión estable y no debe modificarse directamente.  
- Cada feature debe desarrollarse en su propia branch, modificando solo la carpeta correspondiente.  
- Los cambios se integran a través de Pull Requests, que deben ser revisados para asegurar que solo afectan la feature correspondiente.
