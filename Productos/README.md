# Feature Productos

Esta carpeta contiene los recursos específicos de la **gestión de Productos** dentro del ERP.  
Incluye los archivos necesarios para crear, editar y mostrar productos en la sección de Almacén.

---

## 📂 Contenido de la carpeta

- `estilo.css` — Estilos específicos para la interfaz de Productos.  
- `Productos.php` — Formulario para insertar y editar productos en la base de datos.  

---

## 🛠️ Funcionalidades

La feature Productos permite:

- Registrar nuevos productos mediante el formulario.  
- Editar productos existentes.  
- Visualizar los productos en una tabla ordenada y funcional.  

---

## 🔄 Flujo de trabajo

- Todos los cambios relacionados con Productos deben hacerse en la rama `Rama/Productos`.  
- No modificar otras carpetas (`Platos`, `Proveedores`, `Compartido`) desde esta branch.  
- Los cambios se integran a `main` mediante Pull Requests, asegurando que solo se vean los archivos de Productos.
